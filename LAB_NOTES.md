# React Lab — Quick Revision Notes

## Experiment 1 — Text Input

**Concepts:** functional component, useState, controlled input, onChange, state-driven rendering.

The input value is stored in React state. Every change updates the state and React renders the current value.

## Experiment 2 — Header and Footer

**Concepts:** component decomposition, props, reusable components.

The parent passes title, tagline and copyright values to child components through props.

## Experiment 3 — Counter

**Concepts:** useState, event handlers, functional state updates, controlled number input.

The counter changes through React event handlers, with a user-defined step value.

## Experiment 4 — To-Do List

**Concepts:** array state, map(), conditional rendering, event handling, immutable state updates.

Operations: add a task, toggle completion, delete a task and display an empty-state message.
